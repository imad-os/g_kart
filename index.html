How to Play

Action Gamepad (Primary) Samsung TV Remote Keyboard
Steer Left / Right Left Stick / D-Pad Left / Right Arrows Arrow Left / Right or A / D

Brake / Reverse LT / B Button Down Arrow Arrow Down or S
Hop & Drift Boost RB / X Button (Hold) Hold OK while turning Hold Spacebar in turns
Use Question Item LB / Y Button Press OK when holding item Shift / Enter
Pause / Back Start Button Back / Return Key Escape / P
