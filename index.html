🎮 HOW TO PLAY

🎮 GAMEPAD (MY PC)
  • Steer: Left Stick / D-Pad
  • Gas: RT / A (South)
  • Brake/Rev: LT / B (East)
  • Hop & Drift: RB / X (West)
  • Use Item: LB / Y (North)
  • Pause: Start / Options
📺 SAMSUNG TV REMOTE
  • Steer: Left / Right Arrows
  • Gas: Up Arrow (or enable Auto-Gas!)
  • Brake: Down Arrow
  • Use Item: OK / Enter Button
  • Back / Pause: Return / Back
⌨️ KEYBOARD
  • Steer: Left/Right or A/D
  • Gas: Up Arrow or W
  • Brake/Rev: Down or S
  • Hop & Drift: Spacebar
  • Use Item: Shift or Enter
  • Pause: Escape or P
⚡ ROCKET START: Hold Accelerate right when countdown hits "2" for an instant launch turbo!
🔥 DRIFT BOOST: Hold Space / RB / X while steering around corners. Watch sparks turn Blue ➔ Orange ➔ Purple, then release for a massive speed burst!
🎁 QUESTION-BOX ITEMS: Smash through glowing cubes for Turbo Mushrooms, Homing Rockets, Bananas, Star Shields, and Lightning Zappers!
